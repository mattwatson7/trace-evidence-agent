# Suggested project description

https://github.com/mattwatson7/trace-evidence-agent

Trace is a local evidence investigation agent for engineering decisions. It searches
documents, cross-checks numerical discrepancies, and produces an auditable brief
with exact source quotations and an execution trail. It runs without API keys or
package installation, with optional local LLM synthesis through Ollama. The repo
includes a working fictional launch investigation, architecture and trade-offs,
72 automated tests, and documented browser acceptance checks.
