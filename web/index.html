AN INSPECTABLE AGENT

Less magic.
More receipts.

Trace follows a bounded investigation loop: plan search terms, retrieve passages with BM25, expand the search, verify quotes, and compare explicit numerical statements.

Default mode is extractive: findings are real quotations, not AI-generated answers. Optional Ollama adds local language-model synthesis with citation-ID validation.

Lexical matching can miss paraphrases. A numerical discrepancy may reflect different dates or conditions. A valid citation does not guarantee that an AI summary is accurate. Inspect the sources before acting.
